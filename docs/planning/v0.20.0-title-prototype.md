# Increment 6: Concept B title prototype

Baseline: `4782e1f297e8d591e2e7b5911973b118b2a551e1`, on
`feature/0.20.0-tiny-heroes-big-tea-problems`.

## Design and scope

The title is an illustrated tea label: warm cream, tea green, burgundy, fine
gold rules, system serif lettering, and an original silver spoon with a red
cape. Three small ants carry an oversized sugar cube. The release identity is
**Tiny Heroes, Big Tea Problems**, with **Now with More Bugs!** as its tagline.
No downloaded artwork, fonts, dependencies, or image-generation assets are used.

`public/title-hero.svg` is editable vector artwork, built from paths, simple
shapes, and reusable leaf/ant symbols.
`styles/title.css` isolates the label palette, frame, typography, menu, and
responsive rules. These are a direction for later presentation work, not an
application of the theme to other screens. Existing pixel-art fixtures and the
old renderer's unit coverage remain intact; that renderer is no longer loaded
by the opening screen.

## Interaction and accessibility

Start / Continue and How to play are native HTML buttons. Both open the existing
instruction overlay, preserving title → controls → first cup and saved-pot
continuation. The graphics button uses the same toggle and persisted preference
as Tea Break. Other settings remain available through Tea Break. (Since the quick sound
switch, `v0.20.0-quick-audio-toggle.md`, a fourth native button, the speaker,
sits at the label's top right, or in the centred action row on an upright
phone, and joins the focus loop.)

The modal title traps focus across its three buttons in both directions. Enter
activates the focused action; repeat/held Enter remains blocked until keyup,
including after the instruction screen opens. Space and Escape retain their
existing onboarding protections. The title and controls continue blocking
simulation and gameplay input. Decorative content is hidden from assistive
technology and cannot intercept pointers. The title and release copy are HTML,
with a visible burgundy keyboard-focus outline and at least 44px action targets.

The only animation is gentle cup steam, stepped by the existing `createLoop()`.
It uses local cosmetic time, never simulation state or randomness. It stops on
Low graphics, reduced motion (including live changes), hidden documents, and
title dismissal. The illustration and menu work with static steam. The spoon's
cape and the illustrated ants are deliberately static.

## Responsive composition

Desktop and landscape layouts place lettering and controls beside the artwork.
Portrait phones stack title, illustration, and menu. Short and narrow screens
shrink the illustration and omit secondary decorative copy. The title dialog can
scroll if accessibility zoom or an unusually small window needs more space.
Automated fitting checks cover 1920×1080, 1280×720, 800×600, 844×390, 390×844,
and 320×568 in Chromium, Firefox, and mobile Chromium emulation.

## Remaining review decisions

- Approve the original illustration and system serif lettering, or request an
  art/lettering refinement before applying this direction elsewhere.
- Approve the shared controls-first destination for Start / Continue and How to
  play; a separate instructions-only return path is outside this prototype.
- Decide whether steam alone provides enough movement. Cape or illustrated ant
  animation is optional future presentation work, not new ant behavior.

Physical-device testing and human visual/accessibility review remain outstanding;
browser emulation does not establish those results. Weekday background palettes,
instruction/Tea Break restyling, gameplay, and existing ant behavior are unchanged.
No version bump or remote publication is part of this increment.
