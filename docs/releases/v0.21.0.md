# 0.21.0 — Keeping Count

The spoon has started keeping a tally. It is a very small tally, and it has no
idea who you are.

- **Cookie-free analytics:** the published game now uses Umami to estimate visits,
  game starts, progress milestones and active playtime. We do not send gameplay
  inputs, scores or saved games. The provider processes limited browser and
  network information for aggregate reporting.
- **Your choice:** add `?analytics=off` to the game URL to disable analytics for
  that visit. The tracker also stays off when your browser sends Do Not Track.
  The game plays the same if the tracker is blocked.
- **Keyboard hints restored:** upgrade and Tea Shortage choices show their number
  keys again in Compact View and narrow windows.
- **A new field guide:** the instructions now match the vintage title screen, with
  parchment, tea-green lettering, gold borders and rectangular buttons.

Gameplay and saved pots are unchanged. Earlier saved pots continue.

The analytics are new, so they have no findings yet. Any picture of retention can
only build up after this release, and Umami's returning-visitor figures describe
returning website visitors, not identifiable players. See
[how the counting works](../ANALYTICS.md).
